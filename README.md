# Bakin 歩行グラフィック一括パレット変換ツール

RPG Developer Bakin向け歩行グラフィックの色違い素材を、キャラクター単位で一括生成するWindowsデスクトップツールです。

## 現在の機能

- フォルダー直下にある複数のPNGファイルを読み込み
- `キャラクター名_アニメーション名.png` の形式を解析
- キャラクター名ごとにファイルをグループ化
- キャラクターごとのアコーディオンでアニメーション画像を表示・選択
- 選択したPNG画像をピクセル補間なしでプレビュー
- 画像で使われている色を、使用頻度・ピクセル数とともに表示
- PNG以外、および命名形式に合わないファイルを無視

パレット編集・一括変換・JSON設定保存は、今後の開発段階で実装します。

## 開発環境

- Windows 10 / Windows 11
- Visual Studio 2022（.NETデスクトップ開発ワークロード）
- .NET 8

## 開き方

1. `BakinWalkingPaletteTool.sln` をVisual Studioで開きます。
2. `BakinWalkingPaletteTool` をスタートアッププロジェクトに設定します。
3. `F5` キーで実行します。

## 使い方

1. 「フォルダーを選択...」を押します。
2. 歩行グラフィックのPNGファイルが入っているフォルダーを選びます。
3. 左側でキャラクター名を展開し、アニメーション画像を選びます。
4. 右側に画像プレビューとカラーパレットが表示されます。

## 想定するファイル名

```text
キャラクター名_アニメーション名.png
```

例：

```text
villager01_wait.png
villager01_walk.png
villager01_run.png
```
