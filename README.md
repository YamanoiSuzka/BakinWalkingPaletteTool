# PNG ドット絵パレット変換ツール

PNGドット絵の色変更と、RPG Developer Bakin向け歩行グラフィックのキャラクター単位一括変換に対応するWindowsデスクトップツールです。

詳しい操作方法は[操作マニュアル](MANUAL.md)を参照してください。

## 現在の機能

- フォルダー直下にあるすべてのPNG、または単体PNGファイルをボタン／ドラッグ＆ドロップで読み込み
- `キャラクター名_アニメーション名.png` の形式を解析
- ファイル名の最初の`_`でキャラクター名とアニメーション名を分割
- `thumb.png`および`*.thumb.png`は読み込み対象外
- キャラクター名ごとにファイルをグループ化
- 命名形式に合わないPNGは、1ファイルずつ独立して編集
- キャラクターごとのアコーディオンでアニメーション画像を表示・選択
- 選択したPNG画像をピクセル補間なしでプレビュー
- プレビュー画像をマウスホイールで25%～1600%に拡大・縮小
- 画像で使われている色を、使用頻度・ピクセル数とともに表示
- パレットの色をクリックし、カラーピッカーまたはHEX／RGBA入力で指定した色へ同じキャラクターの全アニメーションを一括置換
- パレットとプレビューの左クリックで色置換、右クリックで複数選択・選択解除
- パレットは透明度を含む`#RRGGBBAA`形式で表示し、完全透明色も保持
- 全選択・全選択解除と、専用ダイアログでの色相・彩度・明度・透明度の一括調整
- 調整値はスライダーまたは数値入力で指定し、パラメータを一括リセット可能
- キャラクターごとに独立したUNDO・REDO（`Ctrl+Z` / `Ctrl+Y`）
- 単体画像と選択キャラクターの全アニメーションを、上書きまたは別名で保存
- PNG以外のファイルを無視

JSON設定保存は、今後の開発段階で実装します。

## 開発環境

- Windows 10 / Windows 11
- Visual Studio 2022（.NETデスクトップ開発ワークロード）
- .NET 8

## 開き方

1. `PixelRecolor.sln` をVisual Studioで開きます。
2. `PixelRecolor` をスタートアッププロジェクトに設定します。
3. `F5` キーで実行します。

## 使い方

1. 「フォルダ選択」または「PNG選択」を押すか、PNG／フォルダーを画面へドラッグ＆ドロップします。
2. PNG画像が入っているフォルダー、または編集する単体PNGを指定します。
3. 左側で画像グループを展開し、編集する画像を選びます。
4. 右側に画像プレビューとカラーパレットが表示されます。
5. パレットの色をクリックし、同じダイアログ内のカラーピッカーまたはHEX／RGBA入力で置換後の色を選びます。
6. 同じキャラクターの別アニメーションを選ぶと、共通色にも置換が反映されます。
7. 「保存する」から、保存名と保存先を指定します。同じ名前と保存先なら上書き確認が表示されます。

たとえば `villager01` を `villager01_red` として保存した場合：

```text
villager01_wait.png → villager01_red_wait.png
villager01_walk.png → villager01_red_walk.png
villager01_run.png  → villager01_red_run.png
```

## 想定するファイル名

```text
キャラクター名_アニメーション名.png
```

例：

```text
villager01_wait.png
villager01_walk.png
villager01_run.png
```
